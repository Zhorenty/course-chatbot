# Открытые задачи вне кода

Каркас MVP в репозитории собран. Живой запуск упирается в доступы, инфраструктуру и тексты. Ниже — кто что делает.

---

## От тебя (разработчик / запуск контура)

Пока нет кассы и канала, бот уже можно гонять локально: `/start`, гайд-заглушка, админка, ручная отметка оплаты.

### Инфра

- [ ] VPS (SmartApe или аналог), Docker + Compose, постоянный диск под `./data` — пошагово: [`DEPLOY.md`](DEPLOY.md)
- [ ] Домен или IP с HTTPS **только если** касса шлёт webhook (ЮKassa почти наверняка; LeadPay — по итогам спайка). Long polling Telegram на webhook не переводим
- [ ] Прописать `.env` на сервере из `.env.example` (токен, админы, канал, касса, Sheets)
- [ ] Для контейнера: compose ставит `PAYMENT_WEBHOOK_BIND=0.0.0.0:8080` и публикует только `127.0.0.1:8080` на хосте. Снаружи — reverse proxy. Задай `PAYMENT_WEBHOOK_SECRET` до включения живой кассы.
- [ ] После сдачи: доступы VPS, `.env`, бэкапы SQLite — заказчице, копии бота себе не оставлять

### Google Sheets (срез `FUNNEL`)

- [ ] Создать Google-таблицу (пустую) **или** взять ту, что пришлёт заказчица
- [ ] Google Cloud: проект → включить Google Sheets API → service account → JSON в `secrets/google-sheets.json` (не в git)
- [ ] Выдать сервисному аккаунту доступ **редактора** на таблицу
- [ ] Прописать `GOOGLE_SHEETS_SPREADSHEET_ID`, `GOOGLE_SHEETS_CREDENTIALS_PATH`, `GOOGLE_SHEETS_WRITE_ENABLED=true`
- [ ] Проверить, что вкладка `COURSES` (`gid=0`) заполнена (цена/даты) и `FUNNEL` пересобирается ботом (`FUNNEL` руками не править)

### Telegram

- [ ] Взять токен у заказчицы **или** согласовать, что бота заводишь ты, потом отдаёшь
- [ ] Прописать `BOT_TOKEN`, `ADMIN_USER_IDS` (через @userinfobot)
- [ ] Канал запуска уже создан: https://t.me/+KHNc40Z77iUwYzVi (только чтобы зайти и добавить бота админом с правом приглашать). Прописать числовой `COURSE_CHANNEL_ID` (`-100…`). Эту ссылку ученикам **не** отправлять — только одноразовый `createChatInviteLink`
- [x] PDF гайда лежит в `assets/guide.pdf` («Гайд Язык цвета»). Бот отдаёт файл сам; после первой отправки кэширует Telegram `file_id`. Админ по-прежнему может прислать новый PDF в личку.

### Касса (спайк 1–2 дня, блокирует автостатус)

- [ ] Получить доступы LeadPay (токен «Настройки → Для внешних систем»)
- [ ] Проверить: персональная ссылка (`/rest/v3/bothelp/link`) **и** сигнал боту, что деньги пришли (webhook / pay_status)
- [ ] Если нет уникального URL + автостатуса → переключить `PAYMENT_PROVIDER=yookassa`, ключи магазина, HTTPS на sidecar
- [ ] Тестовый платёж 10 ₽, когда шлюз выбран
- [ ] Пока токена нет, бот в режиме ручного override (админ «отметить оплаченным»)

### Цены и оферта (вкладка `COURSES`, gid=0)

В Google-таблице, первый лист: полная цена **18 000 ₽**, предоплата **5 000 ₽**, доплата до **05.10.2026**, старт курса **12.10.2026**. Бот читает это при старте и по кнопке «Обновить Google Sheets». Перед кассой — два чекбокса оферты и ПДн; кнопка «Перейти к оплате» без обеих галочек не открывает ссылку.

- [ ] `OFFER_URL` — если появится страница/PDF публичной оферты, прописать; в сообщении станет ссылкой. Пока только текст согласия
- [ ] Не публиковать постоянный invite канала в сообщениях бота

## От заказчика

Ориентир по организационке из ТЗ: ближайшие дни. Тексты цепочки каркас не блокируют.

### Чтобы закрыть спайк кассы и вывести бота на её контур

- [ ] Доступы **LeadPay** (кабинет / токен для внешних систем)
- [ ] @username бота (или согласие, что заведём и отдадим)
- [ ] Закрытый канал запуска есть; осталось сделать бота админом с правом приглашать (числовой id канала — в `.env`, не invite-ссылка)
- [x] PDF гайда («Гайд Язык цвета»)
- [x] Цена 18 000 ₽, предоплата 5 000 ₽, доплата 5 октября, старт 12.10
- [ ] Список админов: Telegram user id через @userinfobot
- [ ] Google-таблица под срез (или «заведите пустую»)
- [x] Текст согласия с офертой и ПДн перед «Перейти к оплате»
- [ ] Ссылка на полный текст Публичной оферты (`OFFER_URL`), если будет отдельная страница/файл

### Для живого запуска (параллельно, не блокирует каркас)

- [ ] Все тексты и цепочка прогрева. Первое сообщение сразу после гайда в боте уже уходит как заглушка — подменим, когда пришлёте
- [ ] Интервалы двух касаний «не оплатил», если не оставляем «через несколько часов» (сейчас 6 ч) и «через сутки» (24 ч)
- [ ] Окно «не писать ночью», если не 10:00–21:00 МСК
- [ ] Тестовый платёж в кассе (10 ₽), когда шлюз выбран

Без полной цепочки бот тестируется на заглушках. В прод с продающим прогревом — после copy.

## Что уже сделано в коде (чтобы не дублировать работу)

- Воронка: метки `/start`, гайд без анкеты, шаг 0 прогрева сразу, «Не писать», CTA «Записаться» до выдачи доступа
- Оплата за `PaymentGateway`: LeadPay / ЮKassa / manual, идемпотентный callback, предоплата без invite, рассрочка только после списания
- Одноразовый invite канала запуска, перевыдача со revoke, вход по `chat_member`
- Админка в личке: поиск, карточка, ручной paid/deposit/cancel, рассылка «гайд и не купили»
- Срез Google Sheets `FUNNEL` + каталог `COURSES` (`gid=0`), тихие часы джобов, dedupe после рестарта, Docker Compose

Не сделано и **не должно** делаться в MVP: второй продукт (ноябрь), email/телефон, Telegram Payments, возврат через API кассы, лимит мест.
